# Blockplan

Bauhelfer für große Minecraft-Projekte (Fabric 26.3): Materialliste, Schichtplan, 3D-Ansicht, Baupläne pro Objekt
und Live-Abgleich mit der Welt.

- `web/index.html` – die Website. Die Mod lädt sie beim Weltstart automatisch von hier (`/blockplan update` prüft sofort).
- `mod/` – Quelltext der Fabric-Mod. Bauen: `gradlew.bat build`, Anleitung in `mod/ANLEITUNG.md`.

Bauplan-Inhalte (z. B. gekaufte Welten) liegen nur lokal und gehören nicht in dieses Repo.
